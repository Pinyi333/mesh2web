# @mesh2web/presets

Optimization presets (`hero`, `product`, `ambient`) and lighting presets
(`studio-soft`, `studio-hard`, `outdoor`, `neon`, `flat`) shared by
[mesh2web](https://github.com/pinyi333/mesh2web) packages, as plain JSON.

```js
import { optimizePresets, lightingPresets } from '@mesh2web/presets';
```
