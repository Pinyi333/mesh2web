# Security Policy

mesh2web parses untrusted 3D files (CLI, Studio) and runs in visitors' browsers
(`<web-model>`). If you find a vulnerability, please **do not open a public
issue**. Report it privately via
[GitHub Security Advisories](https://github.com/pinyi333/mesh2web/security/advisories/new).

We aim to acknowledge reports within 7 days. Supported versions: the latest
minor release of each `@mesh2web/*` package.
